CTC & Salary Calculator | Microsoft Excel

📌 Project Overview

The CTC & Salary Calculator is an Excel-based salary calculation tool designed to simplify the process of understanding annual Cost to Company (CTC), monthly gross salary, salary components, deductions, and estimated take-home pay.

The workbook includes a dedicated salary calculation sheet and an analytical dashboard to present salary information in a structured and easy-to-understand format.

🎯 Project Objectives

Calculate monthly and annual salary components.

Understand the breakdown of annual CTC.

Calculate estimated gross salary and take-home salary.

Analyse earnings and deductions.

Present salary information through visual dashboards.

Simplify salary structure analysis using Microsoft Excel.
